# LCM 2.2 · CONCEPTOS DE FÁBRICA DEL NÚCLEO
# No son hechos del mundo (capitales, fechas, personas): son conceptos cotidianos, cómo se agrupan y qué es típico de cada clase.
# Capas de abstracción: cada clase hereda de las que tiene encima (gorrión < pájaro < ave < animal < ser vivo).
# Una propiedad dicha en una capa vale para las de abajo, salvo EXCEPCIÓN declarada más cerca («los pingüinos no vuelan»).
# Formato:
#   [taxonomia]    clase: miembro, miembro/f, ...        (/m o /f fija el género cuando no se deduce de la terminación)
#   [propiedades]  clase: verbo complemento; no verbo complemento
#   [partes]       todo: partes, tal como se dicen (ruedas, motor)
#   [contrarios]   a/b, c/d
#   [grupos]       nombre: relación, relación             (capas de abstracción sobre relaciones entre personas)
#   [efectos]      verbo: estado en que queda lo que recibe la acción («romper» -> «roto»)
